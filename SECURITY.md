# Security policy

## Supported versions

Security fixes are provided for the latest released version of Quran Player.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature on the repository Security
tab. Do not publish credentials, Home Assistant access tokens, private URLs, entity
inventories, or exploit details in a public issue.

Include the Quran Player version, Home Assistant version, a minimal reproduction,
and the security impact. Remove or replace all private values before attaching logs.

For ordinary playback failures and feature requests, use the public issue templates.
